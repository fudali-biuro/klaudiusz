# Marketing – biurko Oli 📣

- `produkty.md` – **ściąga faktów** (ceny, materiały, kolory, kanały sprzedaży). Tylko stąd bierzemy dane do postów.
- `kalendarz-RRRR-MM.md` – plan publikacji (co, kiedy, gdzie, jakie zdjęcie, status).
- `posty/RRRR-MM-DD-<temat>.md` – gotowe posty do wklejenia (Instagram, Facebook, Pinterest EN), z kolejnością zdjęć.
- `zdjecia/<produkt>/` – zdjęcia od Pablo.

**Statusy postów:** 📝 szkic → 👀 do akceptacji Pablo → ✅ zaakceptowany → 📅 zaplanowany → 🚀 opublikowany.
Nic nie idzie do publikacji bez akceptacji Pablo.

weekend o połowę słabszy.
